# 📚 Documentation du Projet vitalCHECK

Bienvenue dans la documentation du projet **vitalCHECK**. Ce dossier contient la documentation détaillée de toutes les fonctionnalités du projet, tant pour le backend que pour le frontend.

## 🎯 Vue d'Ensemble du Projet

vitalCHECK est une **application web full-stack** d'évaluation de santé d'entreprise. Elle permet aux entreprises de réaliser un diagnostic complet de leur santé organisationnelle à travers un questionnaire structuré en plusieurs piliers (RH, Finance, Stratégie, etc.).

L'application est construite sur la stack **MERN** :

- **M**ongoDB : Base de données NoSQL
- **E**xpress.js : Framework backend Node.js
- **R**eact : Librairie frontend (avec Vite)
- **N**ode.js : Environnement d'exécution backend
